# Cambio de precio manual en la balanza Systel

Esta guía muestra, de forma rápida y práctica, cómo modificar el precio de un PLU **directamente en la balanza Systel**, sin utilizar el software de gestión.

---

## 1. Acceder al modo de configuración de precios

1. Encienda la balanza y espere a que el panel LCD muestre el menú principal.
2. presione la tecla **Pre emp** para ingresar como administrador. La clave por defecto es **1234**.
3. Use las teclas **↑/↓** para navegar hasta **"4.Artículos ABM"** y presione **Enter**.
4. Use las teclas **↑/↓** para navegar hasta **"Cambiar precio"** y presione **Enter**.

---

## 2. Buscar el PLU a modificar

1. En la pantalla de búsqueda, introduzca el código **PLU** usando el teclado numérico.
2. Pulse **Enter** para confirmar.
3. La balanza mostrará el registro del PLU con sus precios actuales.

---

## 3. Editar el precio

1. Digite el nuevo precio con el teclado numérico.
2. Confirme pulsando **Enter**.

---

## 4. Guardar los cambios

1. Después de editar, seleccione **"Guardar"** o **"Aceptar"**.
2. La balanza mostrará un mensaje de confirmación: *"Precio actualizado"*.

---

## 5. Verificar la actualización

1. Salga al menú principal y vuelva a **"Consultar PLU"**.
2. Busque nuevamente el mismo código y compruebe que el precio mostrado coincide con el nuevo valor.

---

> **Nota:** Sólo el personal con **permisos de administrador** o **gestor de precios** puede acceder al menú de cambio de precio. .
